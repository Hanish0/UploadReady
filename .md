# Airtel Reimbursement Automation – V1

## Overview

A web application that simplifies monthly telecom reimbursement processing.

The user uploads:
1. Airtel Bill PDF
2. Payment Receipt PDF

The application:
- extracts reimbursement details
- removes unnecessary pages
- merges required pages into a single PDF
- provides copy-to-clipboard actions for each field

---

# Problem Statement

Currently, the reimbursement process involves:

- manually opening PDFs
- finding invoice details
- copying GST values
- deleting unnecessary pages
- merging PDFs

This is repetitive every month.

The goal is to reduce the workflow to:
1. Upload PDFs
2. Click Generate
3. Download final reimbursement package

# Processing

## PDF Extraction

Extract:
- Invoice Number
- Vendor GST Number
- CGST
- SGST
- Invoice Amount
- Paid Amount
- Billing Period
- Mobile Number

---

## PDF Cleaning

Keep only:
- Receipt PDF
- Bill Page 1
- Bill Page 3
- Bill Page 4

Remove:
- payment summary pages
- tariff pages
- unnecessary details
